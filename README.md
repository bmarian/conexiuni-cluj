# Conexiuni Cluj

Real-time public transit tracker for Cluj-Napoca. 
Shows live bus positions, next departures, full timetables, and stop information — all in a mobile-first web app.

## Data sources

- **[Tranzy](https://tranzy.ai)** — GTFS static data (routes, stops, shapes, stop times) and live vehicle positions for Cluj
- **[CTP Cluj](https://ctpcj.ro)** — official timetable
